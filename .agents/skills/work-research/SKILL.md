# Research

Define the decision the user needs to make and the constraints that could change the answer. Infer reasonable defaults from context and continue independent work while asking for a genuinely important missing detail.

## Evidence

- Start with official documentation, original repositories, papers, release notes, or the people who made the claim. Use social posts to discover a source; inspect the source before recommending or installing it.
- Open the relevant content. A search snippet, star count, or promotional description is not sufficient evidence of quality.
- For software, record the project owner, canonical URL, version or commit, last relevant update, compatibility, and license when installation or redistribution is involved.
- Separate popularity, maintenance activity, author authority, and demonstrated effectiveness. Do not label a collection state of the art without a relevant comparative evaluation.
- Record when evidence was checked. A recent repository push can concern unrelated files; distinguish it from the selected feature's update.
- When sources disagree, identify the difference in version, date, or scope. State unresolved uncertainty rather than choosing the convenient claim.

## Recommendation

Compare only the options that could plausibly fit. Explain the material tradeoffs and give a clear recommendation. Prefer a small useful set over a broad catalog when the user wants a working setup.

Place citations beside the claims they support. For a durable report, include source URLs and a checked date; do not make a transient search reference the only citation.

For third-party instruction packs, inspect activation scope, dependencies, executable files, hooks, permission assumptions, and overlap with installed capabilities before enabling them. Preserve provenance and licenses. Fetching a repository is not authorization to execute its setup scripts.

If the request includes implementation, carry the recommendation into the authorized local work and verify the result. Keep the research report distinct from claims of runtime verification.
